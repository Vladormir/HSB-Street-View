Google Street View but for Hypixel SkyBlock.

Built using : 
* BlueMap for the rendering world files in browsers
* The valuable help from the folks from BlueMap discord
* SimpleWorldDownloader for downloading worlds from Skyblock
* Axiom for building
* wWaypoints for easier navigation in MC worlds
* Minecraft textures
* Hypixel SkyBlock textures

Not built using :
* ~~AI~~ nvm used GPT to convert 117 kB worth of waypoints into BlueMap syntax
